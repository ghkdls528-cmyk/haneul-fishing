# 하늘이의 여수 낚시

여수 바다를 배경으로 한 귀여운 도트 낚시 게임입니다. 휴대폰 브라우저(세로 화면)에 맞춰 만들었습니다.

- **바로 플레이**: https://ghkdls528-cmyk.github.io/haneul-fishing/
- 휴대폰에서 위 주소를 열고, 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.
- 진행 상황은 그 브라우저 안에 저장됩니다. 다른 기기나 다른 브라우저로는 옮겨지지 않습니다.

## 개발
- 빌드: `python build.py` → `dist/haneul-fishing.html` (이미지까지 들어간 HTML 파일 하나)
- `main`에 올리면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 배포합니다.
- 작업 규칙: `CLAUDE.md` · AI 나눠 쓰기: `docs/WORKFLOW.md` · 이력: `docs/CHANGELOG.md`
