낚시왕 왕낚시 개인정보처리방침

시행일: 출시일에 맞춰 적어 주세요 · 적용 대상: 웹 게임과 안드로이드 앱 「낚시왕 왕낚시」

1. 수집하는 개인정보

이 게임은 개인정보를 수집하지 않습니다. 회원가입, 로그인, 이름·이메일·전화번호 입력, 위치 정보, 연락처, 사진·파일 접근, 광고 ID 사용이 없습니다.

2. 기기 안에만 저장되는 정보

게임 진행 기록(레벨, 골드, 도감, 장비, 설정 등)은 사용자 기기 안의 저장 공간(브라우저/앱 로컬 저장소)에만 저장되며, 개발자나 다른 서버로 전송되지 않습니다.

  • 앱을 삭제하거나 브라우저 사이트 데이터를 지우면 기록도 함께 지워집니다.
  • 설정 › 기록 옮기기의 「세이브 코드」는 사용자가 직접 복사해서 옮길 때만 쓰이며, 자동으로 어디에도 전송되지 않습니다.

3. 외부 서비스

  • 광고, 결제, 분석(통계) 도구를 사용하지 않습니다.
  • 화면 글꼴(Jua)을 불러오기 위해 Google Fonts(fonts.googleapis.com)에 접속할 수 있으며, 이때 일반적인 인터넷 접속과 같이 기기의 IP 주소 등 접속 정보가 Google에 전달될 수 있습니다. 인터넷이 없으면 기기 기본 글꼴로 표시됩니다.

4. 권한

안드로이드 앱은 인터넷·진동 권한(둘 다 설치 시 자동 허용되는 일반 권한)만 사용하며, 위치·카메라·연락처·저장소 등 다른 권한은 요청하지 않습니다.

5. 아동

이 게임은 어떤 연령의 사용자에게서도 개인정보를 수집하지 않습니다.
