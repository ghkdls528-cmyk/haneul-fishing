# **4.14 사양서 — 낚시의 긴장감과 손맛 개선**



구현 기준 확정안

기존 콘텐츠 보존



## **목표**

1. 최고 단계 장비에서도 물고기를 낚는 과정에 적절한 긴장감이 유지되도록 전투 밸런스를 개선합니다.
2. 물고기의 희귀도·크기·저항 패턴에 따라 낚시 경험과 소요 시간이 달라지도록 합니다.
3. 낚시 결과에 플레이 실력을 평가하는 피드백을 추가해, 단순히 물고기를 잡는 것 이상의 성취감을 제공합니다.

**이번 업데이트의 핵심은 물고기를 무조건 오래 잡게 만드는 것이 아닙니다.** 장비가 좋아지면 유리해지지만, 강한 물고기는 끝까지 집중해야 잡을 수 있도록 만드는 것입니다.

## **구현 범위**

| 기능   | 내용                          |
| ---- | --------------------------- |
| 기능 1 | 물고기별 저항·장비 밸런스 재조정          |
| 기능 2 | 물고기 체급·희귀도·저항 패턴별 낚시 전투 차별화 |
| 기능 3 | 낚시 실력 평가 및 개인 기록            |

기존 입질 4종, 저항 패턴 10종, 위기 링, 보스 6종, 낚시 방식 6종은 그대로 활용합니다. 새로운 낚시 조작이나 별도 게임 모드는 추가하지 않습니다.

## **기능 1. 물고기 저항과 장비 밸런스 재조정**

\- **왜 재미있는가:** 좋은 장비를 갖추면 확실히 편해지지만, 강한 물고기를 잡을 때는 여전히 긴장하고 집중해야 합니다.

### **플레이 흐름**

1. 기존 낚시터에서 기존 방식으로 낚시합니다.
2. 입질이 발생하면 기존처럼 챔질합니다.
3. 물고기와 전투가 시작되면 물고기의 희귀도·크기·저항 패턴과 현재 장비 성능이 전투 난이도에 반영됩니다.
4. 릴 감기와 장력 조절을 통해 물고기를 제압합니다.
5. 줄이 끊어질 위험이 커지면 기존 위기 링이 작동합니다.
6. 물고기를 잡거나 놓치면 기존 결과 화면으로 돌아갑니다.

### **숫자: 전투 시간 기준**

아래 시간은 **최고 단계 낚싯대·릴·낚싯줄을 사용했을 때의 목표 전투 시간**입니다.

전투 시간은 챔질 성공부터 물고기 획득까지로 측정합니다. 입질 대기 시간과 낚시 준비 시간은 포함하지 않습니다.

| 물고기 등급 | 목표 전투 시간 |
| ------ | -------- |
| 잡동사니   | 3초       |
| 일반     | 8초       |
| 고급     | 11초      |
| 희귀     | 15초      |
| 영웅     | 20초      |
| 전설     | 28초      |
| 신화     | 38초      |
| 히든     | 45초      |
| 보스     | 60초      |

[기획 기준] 위 시간은 4.13의 실제 전투 데이터를 측정한 값이 아니라 4.14에서 맞출 목표값입니다.

### **장비 성능 적용**

최고 단계 장비를 기준으로 전투 시간을 설정하고, 장비 단계가 낮을수록 다음 배율을 적용합니다.

| 장비 수준 | 목표 전투 시간 배율 |
| ----- | ----------- |
| 1단계   | ×1.45       |
| 2단계   | ×1.35       |
| 3단계   | ×1.25       |
| 4단계   | ×1.15       |
| 5단계   | ×1.07       |
| 6단계   | ×1.00       |

장비 수준은 낚싯대·릴·낚싯줄의 단계 평균으로 계산합니다. 예를 들어 6·6·4단계라면 평균 5.33단계로 계산합니다.

단, 장비별 기존 장점과 단점은 유지합니다.

- 낚싯대: 기존 힘과 제압 성능에 영향
- 릴: 기존 감기 효율에 영향
- 낚싯줄: 기존 장력 안정성과 파손 위험에 영향

세 장비가 모두 6단계라고 해서 물고기의 저항을 무시할 수 있게 만들어서는 안 됩니다.

### **전투 밸런스 계산 기준**

기본 전투 시간은 다음 요소로 조정합니다.

- 등급별 기본 전투 시간
- 장비 성능
- 물고기 크기
- 저항 패턴

최종 전투 시간은 해당 요소를 반영해 목표값에 맞춥니다. 기존 낚시 계산식과 충돌한다면 기존 시스템을 유지하면서 내부 수치를 조정합니다.

**중요:** 기존 장비의 공격력·감기 속도·장력 수치를 일괄 초기화하지 않습니다. 기존 장비의 상대적인 성능 차이를 보존하면서 전투 결과만 조정합니다.

### **저장할 새 데이터**

기능 1은 기존 전투 계산값을 조정하는 기능이므로 별도 저장 필드는 추가하지 않습니다.

### **화면**

- 기존 낚시 화면 유지
- 장력 게이지 위치와 크기 유지
- 위기 링 위치와 작동 방식 유지
- 새로운 게이지나 별도 조작 버튼 추가 금지

### **기존 기능과의 관계**

- 기존 장비 6단계 및 강화 데이터 보존
- 기존 낚싯대·릴·낚싯줄 스킨 보존
- 기존 물고기 134종의 정보와 이미지 보존
- 기존 보스 6종의 단계별 패턴 보존
- 기존 낚시 방식 6종의 기능 보존

## **기능 2. 물고기 체급과 저항 패턴에 따른 전투 차별화**

\- **왜 재미있는가:** 같은 희귀도의 물고기라도 크기와 행동에 따라 낚는 방법이 달라져 매번 똑같은 전투가 반복되지 않습니다.

### **플레이 흐름**

1. 물고기가 입질합니다.
2. 챔질에 성공하면 해당 물고기의 체급과 기존 저항 패턴이 전투에 반영됩니다.
3. 물고기는 기존 저항 패턴에 따라 움직입니다.
4. 플레이어는 장력 게이지를 보면서 릴을 감거나 놓습니다.
5. 물고기의 저항이 강해지면 기존 위기 링이 발생할 수 있습니다.
6. 물고기를 잡으면 크기와 전투 기록이 결과 화면에 표시됩니다.

### **숫자: 체급 구분**

물고기의 기존 크기 데이터를 이용해 다음과 같이 구분합니다.

| 체급  | 크기 구간               | 전투 시간 배율 |
| --- | ------------------- | -------- |
| 소형  | 해당 어종의 기준 크기 80% 미만 | ×0.85    |
| 보통  | 80% 이상 120% 미만      | ×1.00    |
| 대형  | 120% 이상 150% 미만     | ×1.15    |
| 초대형 | 150% 이상             | ×1.30    |

크기 기준은 각 어종의 기존 기준 크기를 사용합니다. 기준 크기가 없는 어종은 해당 어종의 기존 최소·최대 크기를 기준으로 계산합니다.

### **저항 패턴 차별화**

기존 10종 저항 패턴을 새로 만들지 않고, 각 패턴의 강도와 대응 타이밍을 조정합니다.

| 패턴 특성       | 전투 효과          |
| ----------- | -------------- |
| 짧고 빠른 저항    | 순간적인 장력 상승     |
| 길고 지속적인 저항  | 장시간 감기 효율 감소   |
| 갑작스러운 방향 전환 | 장력 변동 증가       |
| 강한 순간 돌진    | 위기 링 발생 가능성 증가 |
| 저항 후 휴식     | 릴 감기 효율 증가     |
| 반복적인 몸부림    | 감기 타이밍 판단 필요   |
| 좌우 흔들림      | 장력 안정성 관리 필요   |
| 깊은 곳으로 이동   | 감기 효율 감소       |
| 연속적인 돌진     | 장력 관리 난이도 증가   |
| 불규칙한 저항     | 예측과 대응이 어려워짐   |

위 명칭은 플레이어에게 노출할 새로운 패턴명이 아니라 기획상 구분입니다. 실제 게임의 기존 10개 패턴 ID와 연결해 적용합니다.

### **패턴별 수치**

| 패턴 유형   | 장력 변화 배율 | 감기 효율 배율 |
| ------- | -------- | -------- |
| 순간 저항형  | ×1.30    | ×0.85    |
| 지속 저항형  | ×1.05    | ×0.75    |

| 돌진형     | ×1.45    | ×0.70    |
| 휴식형     | ×0.70    | ×1.30    |
| 반복 몸부림형 | ×1.15    | ×0.85    |
| 좌우 흔들림형 | ×1.20    | ×0.90    |

[기획 기준] 위 수치는 패턴별 상대적 강도를 정하는 초기값입니다. 기존 코드의 장력 및 감기 수치와 단위가 다르면 같은 효과를 내도록 환산해야 합니다.

### **밸런스 제한**

- 체급 배율은 최대 ×1.30까지만 적용합니다.
- 패턴 효과와 체급 효과를 무제한 곱하지 않습니다.
- 전투 난이도 보정은 기본값의 0.75\~1.60배로 제한합니다.
- 기존 위기 링의 기회 2회는 유지합니다.
- 기존 물고기별 저항 패턴 배정은 유지합니다.
- 보스는 기존 단계별 패턴을 유지하고 일반 물고기와 별도 밸런스로 조정합니다.

### **보스 전투 시간**

최고 단계 장비 기준으로 보스 6종의 전투 시간을 다음 목표에 맞춥니다.

| 보스 난이도 | 목표 전투 시간 |
| ------ | -------- |
| 1단계 보스 | 45초      |
| 2단계 보스 | 55초      |
| 3단계 보스 | 65초      |
| 4단계 보스 | 75초      |
| 5단계 보스 | 85초      |
| 최종 보스  | 95초      |

기존 보스별 난이도 순서가 다르다면 기존 순서를 유지하고 해당 난이도에 맞춰 배정합니다.

### **저장할 새 데이터**

기능 2 자체에는 새 저장 데이터가 필요하지 않습니다. 기존 물고기 크기, 저항 패턴, 보스 단계 데이터를 그대로 사용합니다.

### **화면**

- 기존 장력 게이지를 유지합니다.
- 기존 입질·저항 애니메이션을 재사용합니다.
- 물고기의 행동에 따라 기존 애니메이션과 장력 변화를 명확하게 연결합니다.
- 별도 조작 버튼을 추가하지 않습니다.

### **기존 기능과의 관계**

- 기존 저항 패턴 10종을 재사용합니다.
- 기존 입질 4종을 유지합니다.
- 기존 위기 링의 2회 기회를 유지합니다.
- 기존 물고기 크기 마스터 시스템을 유지합니다.
- 보스의 단계별 패턴과 기존 보상은 변경하지 않습니다.

## **기능 3. 낚시 실력 평가와 개인 기록**

\- **왜 재미있는가:** 같은 물고기를 잡더라도 얼마나 침착하고 능숙하게 잡았는지 기록되므로, 자신의 낚시 실력을 계속 높이는 재미가 생깁니다.

### **플레이 흐름**

1. 기존 방식으로 물고기를 낚습니다.
2. 낚시가 끝나면 기존 획득 결과 화면에 실력 평가가 추가됩니다.
3. 플레이어는 등급, 전투 시간, 장력 관리 결과를 확인합니다.
4. 물고기별 최고 점수와 최고 크기 기록이 갱신되면 별도 표시합니다.
5. 다음 낚시에서 자신의 기록을 갱신할 수 있습니다.

### **숫자: 실력 평가 기준**

평가 점수는 100점 만점이며, 골드·경험치·물고기 출현 확률에는 영향을 주지 않습니다.

| 평가 항목 | 배점  | 계산 기준                 |
| ----- | --- | --------------------- |
| 장력 관리 | 50점 | 안전 구간을 유지한 시간 비율      |
| 전투 효율 | 30점 | 등급·체급별 목표 시간 대비 실제 시간 |
| 위기 대응 | 20점 | 위기 링 발생 및 성공·실패 기록    |

**① 장력 관리: 50점**

- 기존 장력 게이지를 0\~100으로 환산합니다.
- 안전 구간은 20\~75로 설정합니다.
- 75 초과는 주의 구간으로 기록합니다.
- 85 초과는 위험 구간으로 기록합니다.
- 95 이상은 줄 끊김 직전 상태로 기록합니다.

계산식:

`장력 점수 = 50 × 안전 구간 유지 시간 ÷ 전체 전투 시간`

**② 전투 효율: 30점**

- 기능 1과 기능 2에서 계산한 해당 물고기의 목표 전투 시간을 사용합니다.
- 목표 시간 이내에 잡으면 만점입니다.
- 목표 시간보다 오래 걸리면 점수가 감소합니다.

계산식:

`전투 효율 점수 = 30 × min(1, 목표 전투 시간 ÷ 실제 전투 시간)`

**③ 위기 대응: 20점**

| 전투 결과                | 점수  |
| -------------------- | --- |
| 위기 링 미발생             | 20점 |
| 위기 링 발생, 모두 성공       | 16점 |
| 위기 링 1회 실패           | 8점  |
| 위기 링 2회 실패 또는 물고기 놓침 | 0점  |

위기 링을 성공적으로 사용하는 행위 자체는 과도하게 감점하지 않습니다.

### **최종 등급**

| 점수      | 평가 | 표시      |
| ------- | -- | ------- |
| 90\~100 | S  | 완벽한 낚시  |
| 80\~89  | A  | 능숙한 낚시  |
| 65\~79  | B  | 안정적인 낚시 |
| 50\~64  | C  | 아쉬운 낚시  |
| 0\~49   | D  | 다시 도전   |

소수점은 버리고 정수 점수로 표시합니다.

물고기를 놓친 경우에는 실력 등급을 부여하지 않고 실패 원인만 표시합니다. 실패 기록은 성공 횟수나 최고 점수에 반영하지 않습니다.

### **저장할 새 데이터**

기존 저장 데이터에 다음 항목을 추가합니다.

| 필드 이름 예시                       | 기본값                     | 용도             |
| ------------------------------ | ----------------------- | -------------- |
| `fightRecords`                 | `{}`                    | 물고기별 전투 기록     |
| `fightRecords[id].bestScore`   | `0`                     | 해당 어종 최고 점수    |
| `fightRecords[id].bestTimeMs`  | `0`                     | 해당 어종 최단 전투 시간 |
